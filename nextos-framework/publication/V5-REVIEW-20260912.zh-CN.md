# V5 发布工具评审

本次评审修正的是为发布而准备的收录集中的工具。保留 V5 运行时、NXExtract、接口、原生示例与各移植的冻结快照。未纳入 V6。仓库保持私有。

## 已实施的修正

| 边界 | 发现的缺陷 | 修正 |
| --- | --- | --- |
| 冻结收录集 | 接受额外文件与可执行位被改动 | 要求精确集合、哈希与可执行模式，不接受 symlink |
| V5 标识 | 改动运行时并在其自身 manifest 中改哈希可以蒙混过关 | 同时固定 V5 导出 manifest 的 SHA-256 |
| 工作区 | 强加给被忽略目录中 Git 的数据可能逃逸 | 拒绝 `work/`、`build/`、`inputs/`、缓存与环境文件里的受版本控制内容 |
| ELF 清单 | ELF64 可能被当成一个不加阻拦的 ARMv7 | 校验类别、机器、版本与头大小；指出已被 V5 加载器拒绝的要求 |
| Android 集合 | 接受重复的 base/split 或不同已知版本 | 拒绝重复标识与冲突版本；保留未知字段 |
| 限制 | 按单个 APK 计 8 GiB；在核对 2 MiB 之前就解压了 manifest | 累加全部 APK，并在读取 manifest 之前先校验 |
| 恢复 | 特殊字符会改变 URL；来源信息可能被覆盖 | 对路径编码、比对已 pin 的哈希，并要求文件为新增 |

新的 [V5 collection checks 工作流](../.github/workflows/collection.yml)在 push/PR 上运行完整性检查、双语指南与工具测试。它只使用收录集与合成 fixture。[SDK 完整训练](../.github/workflows/onboarding.yml)仍为手动。没有任何工作流会发布商业数据或游戏产物。

## 补充：Android 运行时指南

[Android 运行时选型](../docs/zh/ANDROID-RUNTIMES.md)整合了八条路线。新增了 GameMaker、Ren'Py、Haxe/hxcpp/Lime 与原生 C/C++ 的 PT/EN 指南，涵盖 bootstrap、ABI、参考文件、解包与诊断。MonoGame/FNA 仍保留在 Android 构建的语境中。

检索默认返回 Android 来源并接受 `--runtime`，同时保留显式指定 `--platform all` 的历史查询。清单只对实际 inspected 过的原生库识别这三大新家族；assets 文件不会被误认成运行时。15 个新测试覆盖该检测、过滤、指南链接、证据哈希以及支持边界的保持。

澄清了 17 项分类，均附已选定快照的路径与哈希。40 个来源仓库已在 2026 年 9 月 12 日核对为 GitHub 公开仓库。未导入任何新的游戏来源。Tightrope 1.0.5-test.1 候选人维持待审；分类既不认证它的字节，也不会把它升级进 V5。

## 证据与边界

初次评审跑通 48 个宿主测试：17 个覆盖范围/完整性，13 个 Android 兼容性，12 个清单/目录，6 个恢复。反证包括 ELF 32/64、split 版本、被改动的 manifest、额外文件、权限、symlink 与模拟 URL。模拟恢复不能证明外部服务器仍然可用。工作流也会执行本补充中新增的 15 个测试；请在 GitHub 上查看绑定到最终提交的结果。

保留的 manifest 的 SHA-256 为 `c038cd9bb1e9bfedc0f24a8b51639fccf5a464a3dfd474b950463315bcb59662`；来源仍为 `framework-v5` / `657fb65a23b5c3b20040e76307b27e6470b1d17c`。验证器核对这一导出的 1.285 个文件以及各移植的收录集。它检查当前工作树与 Git 索引路径，不担保整个历史或 shims 覆盖率。

SDK、ARM 示例、NXExtract 与游戏都没有重新编译或运行。此前的证据保留其自身的字节与边界，见 [ONBOARDING-UPDATE.zh-CN.md](ONBOARDING-UPDATE.zh-CN.md)。未做任何物理测试、ZIP、发布、迁移或可见性变更。
