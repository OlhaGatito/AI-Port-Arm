本目录仅收录由 **NextOS** 创建或整合的 port。据维护者说明，其中包括 **来自 40 个公开仓库的 44 个已选定来源的标题**，以及 **2 条由社区分发的参考**，未包含 GitHub 快照。Freedom Planet 2 已列于这 44 个之中；第一部 Freedom Planet 未予收录。

若要创建另一个 Android port，请从 [runtime 选择器](../../docs/zh/ANDROID-RUNTIMES.md) 开始。[profile 检索](../../tools/find_reference.py) 默认以 Android 来源，并将每个系列映射到 PT/EN 指南；分类结论不构成已证实的支持。
